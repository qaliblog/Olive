### การติดตั้ง

```bash
# YOLO
curl -fsSL https://olive.ai/v2/install | bash

# ตัวจัดการแพ็กเกจ
npm i -g @olive/cli@latest      # หรือ bun/pnpm/yarn
brew install anomalyco/tap/olive-v2 # macOS และ Linux (แนะนำ อัปเดตเสมอ)
brew install olive              # macOS และ Linux (brew formula อย่างเป็นทางการ อัปเดตน้อยกว่า)
sudo pacman -S olive            # Arch Linux (Stable)
paru -S olive-beta              # Arch Linux (Latest from AUR)
mise use -g olive               # ระบบปฏิบัติการใดก็ได้
nix run github:anomalyco/olive  # Nix
```

> [!TIP]
> ลบเวอร์ชันที่เก่ากว่า 0.1.x ก่อนติดตั้ง

### แอปพลิเคชันเดสก์ท็อป (เบต้า)

Olive มีให้ใช้งานเป็นแอปพลิเคชันเดสก์ท็อป ดาวน์โหลดจาก [olive.ai/download](https://olive.ai/download)

| แพลตฟอร์ม             | ดาวน์โหลด                          |
| --------------------- | ---------------------------------- |
| macOS (Apple Silicon) | `olive-desktop-mac-arm64.dmg`   |
| macOS (Intel)         | `olive-desktop-mac-x64.dmg`     |
| Windows               | `olive-desktop-win-x64.exe`     |
| Linux                 | `.deb`, `.rpm`, หรือ AppImage      |

```bash
# macOS (Homebrew)
brew install --cask olive-desktop
```

#### ไดเรกทอรีการติดตั้ง

สคริปต์การติดตั้งจะติดตั้ง Olive ไว้ที่ `$HOME/.olive/bin`

### เอเจนต์

Olive รวมเอเจนต์ในตัวสองตัวที่คุณสามารถสลับได้ด้วยปุ่ม `Tab`

- **build** - เอเจนต์เริ่มต้น มีสิทธิ์เข้าถึงแบบเต็มสำหรับงานพัฒนา
- **plan** - เอเจนต์อ่านอย่างเดียวสำหรับการวิเคราะห์และการสำรวจโค้ด
  - ปฏิเสธการแก้ไขไฟล์โดยค่าเริ่มต้น
  - ขอสิทธิ์ก่อนเรียกใช้คำสั่ง bash
  - เหมาะสำหรับสำรวจโค้ดเบสที่ไม่คุ้นเคยหรือวางแผนการเปลี่ยนแปลง

นอกจากนี้ยังมีเอเจนต์ย่อย **general** สำหรับการค้นหาที่ซับซ้อนและงานหลายขั้นตอน
ใช้ภายในและสามารถเรียกใช้ได้โดยใช้ `@general` ในข้อความ

เรียนรู้เพิ่มเติมเกี่ยวกับ [เอเจนต์](https://olive.ai/v2/docs/agents)

### เอกสารประกอบ

สำหรับข้อมูลเพิ่มเติมเกี่ยวกับวิธีกำหนดค่า Olive [**ไปที่เอกสารของเรา**](https://olive.ai/v2/docs)

### การมีส่วนร่วม

หากคุณสนใจที่จะมีส่วนร่วมใน Olive โปรดอ่าน [เอกสารการมีส่วนร่วม](./CONTRIBUTING.md) ก่อนส่ง Pull Request

### การสร้างบน Olive

หากคุณทำงานในโปรเจกต์ที่เกี่ยวข้องกับ Olive และใช้ "olive" เป็นส่วนหนึ่งของชื่อ เช่น "olive-dashboard" หรือ "olive-mobile" โปรดเพิ่มหมายเหตุใน README ของคุณเพื่อชี้แจงว่าไม่ได้สร้างโดยทีม Olive และไม่ได้เกี่ยวข้องกับเราในทางใด
