### Kurulum

```bash
# YOLO
curl -fsSL https://olive.ai/v2/install | bash

# Paket yöneticileri
npm i -g @olive/cli@latest      # veya bun/pnpm/yarn
brew install anomalyco/tap/olive-v2 # macOS ve Linux (önerilir, her zaman güncel)
brew install olive              # macOS ve Linux (resmi brew formülü, daha az güncellenir)
sudo pacman -S olive            # Arch Linux (Stable)
paru -S olive-beta              # Arch Linux (Latest from AUR)
mise use -g olive               # Tüm işletim sistemleri
nix run github:anomalyco/olive  # Nix
```

> [!TIP]
> Kurulumdan önce 0.1.x'ten eski sürümleri kaldırın.

### Masaüstü Uygulaması (BETA)

Olive ayrıca masaüstü uygulaması olarak da mevcuttur. [olive.ai/download](https://olive.ai/download) adresinden indirebilirsiniz.

| Platform              | İndirme                            |
| --------------------- | ---------------------------------- |
| macOS (Apple Silicon) | `olive-desktop-mac-arm64.dmg`   |
| macOS (Intel)         | `olive-desktop-mac-x64.dmg`     |
| Windows               | `olive-desktop-win-x64.exe`     |
| Linux                 | `.deb`, `.rpm` veya AppImage       |

```bash
# macOS (Homebrew)
brew install --cask olive-desktop
```

#### Kurulum Dizini (Installation Directory)

Kurulum betiği, Olive'u `$HOME/.olive/bin` dizinine kurar.

### Ajanlar

Olive, `Tab` tuşuyla aralarında geçiş yapabileceğiniz iki yerleşik (built-in) ajan içerir.

- **build** - Varsayılan, geliştirme çalışmaları için tam erişimli ajan
- **plan** - Analiz ve kod keşfi için salt okunur ajan
  - Varsayılan olarak dosya düzenlemelerini reddeder
  - Bash komutlarını çalıştırmadan önce izin ister
  - Tanımadığınız kod tabanlarını keşfetmek veya değişiklikleri planlamak için ideal

Ayrıca, karmaşık aramalar ve çok adımlı görevler için bir **genel** alt ajan bulunmaktadır.
Bu dahili olarak kullanılır ve mesajlarda `@general` ile çağrılabilir.

[Ajanlar](https://olive.ai/v2/docs/agents) hakkında daha fazla bilgi edinin.
