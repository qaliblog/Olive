title: "Commands"
description: "Reference for the olive command line."
---

Every command accepts `--help` for its full flag list, for example `olive run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ olive run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: Olive review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @olive/cli
      - run: olive run --standalone --model anthropic/claude-sonnet-5-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ olive run --model anthropic/claude-sonnet-5-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ olive run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ olive run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ olive run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ olive run --agent build "Fix the failing test"
```

Continue a specific session.

```bash
$ olive run --session ses_4f2a1c "Check edge cases"
```

Auto-approve permissions that are not explicitly denied.

```bash
$ olive run --auto "Fix the failing test"
```

View all subcommands and flags.

```bash
$ olive run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ olive mini
```

Continue the last session.

```bash
$ olive mini --continue
```

Start with a model and an initial prompt.

```bash
$ olive mini --model anthropic/claude-sonnet-5-5 --prompt "Summarize this repository"
```

Continue a specific session.

```bash
$ olive mini --session ses_4f2a1c
```

View all subcommands and flags.

```bash
$ olive mini --help
```

## session

Manages sessions.

```bash
$ olive session list
```

Limit the list and print JSON.

```bash
$ olive session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ olive session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ olive session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ olive session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ olive session import session.json
```

Import into a specific directory.

```bash
$ olive session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ olive session --help
```

## auth

Manages AI providers and credentials.

```bash
$ olive auth list
```

List them as JSON.

```bash
$ olive auth list --format json
```

Log in to a provider.

```bash
$ olive auth login anthropic
```

Log in with a specific authentication method.

```bash
$ olive auth login anthropic --method key
```

Log out of a saved account.

```bash
$ olive auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ olive auth switch anthropic work
```

Export saved credentials and import them on another machine. The file contains secrets.

```bash
$ olive auth export anthropic > credentials.json
$ olive auth import credentials.json
```

View all subcommands and flags.

```bash
$ olive auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ olive mcp list
```

Add a remote server.

```bash
$ olive mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ olive mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ olive mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ olive mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ olive mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ olive mcp logout sentry
```

View all subcommands and flags.

```bash
$ olive mcp --help
```

## plugin

Manages plugins.

```bash
$ olive plugin list
```

Include built-in server plugins.

```bash
$ olive plugin list --builtin
```

Install a plugin and add it to the global configuration.

```bash
$ olive plugin add @example/olive-tui
```

Check package plugins for updates.

```bash
$ olive plugin check
```

Update package plugins.

```bash
$ olive plugin update
```

Remove a plugin from global configuration.

```bash
$ olive plugin remove @example/olive-tui
```

View all subcommands and flags.

```bash
$ olive plugin --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ olive serve
```

Bind to all interfaces on a fixed port.

```bash
$ olive serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ olive serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ olive serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ olive pair
```

Use an external URL in the links.

```bash
$ olive pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ olive pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ olive pair --remote --yes
```

View all subcommands and flags.

```bash
$ olive pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ olive service start
```

Restart it.

```bash
$ olive service restart
```

Show its status.

```bash
$ olive service status
```

Stop it.

```bash
$ olive service stop
```

Read a setting.

```bash
$ olive service get hostname
```

Set a setting.

```bash
$ olive service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ olive service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ olive service set env OLIVE_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ olive service unset hostname
```

View all subcommands and flags.

```bash
$ olive service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ olive reload
```

## api

Makes a request to the running server.

```bash
$ olive api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ olive api session.list --param limit=10
```

Send a JSON body.

```bash
$ olive api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ olive api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ olive api --help
```

## debug

Provides debugging and troubleshooting tools.

```bash
$ olive debug agents
```

List configuration sources.

```bash
$ olive debug config
```

Write a heap snapshot of the running background server and print its path.

```bash
$ olive debug heap-dump
```

Write the snapshot into a directory of your choice.

```bash
$ olive debug heap-dump --directory ./snapshots
```

Show global paths.

```bash
$ olive debug paths
```

Print a single path.

```bash
$ olive debug paths db
```

View all subcommands and flags.

```bash
$ olive debug --help
```

## upgrade

Upgrades Olive to the latest or a specific version. Alias: `update`.

```bash
$ olive upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ olive upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ olive upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls Olive. Session data, configuration, and
state are not removed.

```bash
$ olive uninstall
```

Preview what would be removed.

```bash
$ olive uninstall --dry-run
```

View all subcommands and flags.

```bash
$ olive uninstall --help
```
